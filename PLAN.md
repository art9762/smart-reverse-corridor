### Соответствие кейсу

Кейс требует:
1. Систему управления реверсивным движением на участке ремонта (0.5–2 км) — **реализовано**
2. CV-детекцию и трекинг ТС на въезде/выезде — **реализовано** (YOLO + ByteTrack + виртуальная линия)
3. Безопасное переключение фаз (только при пустой зоне) — **реализовано** (FSM с guard-условиями)
4. Адаптивную длительность зелёного — **реализовано** (scheduler с весами)
5. Аварийные режимы (застревание, потеря камеры, спецтранспорт) — **реализовано**
6. Сравнение baseline vs adaptive с метриками — **частично** (bench.py есть, но нет готовых результатов/графиков)
7. Визуализацию/дашборд — **реализовано** (React + SVG + live MQTT)
8. Демо-сценарии — **реализовано** (6 сценариев в симуляторе)

## Порядок выполнения (критический путь)

```
1. Исправить метрики контроллера (Разр. 1: задачи 1.3–1.6)   ← без этого bench.py выдаёт нули
   ↓
2. Прогнать bench.py на стеке (Разр. 2: задачи 2.1–2.2)     ← получаем CSV + графики
   ↓
3. Подготовить слайды + видео (Разр. 5: задачи 5.2–5.3)     ← готовность к выступлению
```

Параллельно (не блокируют друг друга):
- Frontend (Разр. 3) — кнопка mode_switch + панель сравнения + индикатор зоны
- ML (Разр. 4) — демо-видео для кулуаров
- Интеграционные тесты (Разр. 2: задачи 2.4–2.5)
