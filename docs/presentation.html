Ремонт дороги → 2 полосы сужаются в одну

Сейчас: фиксированный таймер

  • 60 сек туда, 60 обратно — всегда одинаково
  • Не знает, что с одной стороны пусто
  • Пробки до 20+ машин в очереди
  • Среднее ожидание ~90 секунд
  • Ручное регулирование = риск ДТП

Светофор, который видит и думает

👁 Компьютерное зрение

YOLOv8 nano + ByteTrack

  • Детекция: легковые, грузовики, автобусы, спецтранспорт
  • Трекинг: устойчивый ID каждого ТС
  • Виртуальная линия пересечения
  • Событие: enter / exit + track_id + class
  • 30+ FPS на edge-устройстве

🧠 Адаптивный планировщик

T_green = clamp(
  base + W_queue × queue_length
       + W_wait × wait_time_other
       + W_truck × truck_count
       − W_empty × other_side_empty,
  GREEN_MIN, GREEN_MAX
)

● Больше очередь → дольше зелёный

● Другая сторона долго ждёт → сокращаем

● Грузовики медленнее → добавляем время

Веса настраиваются оператором на лету через дашборд

🚨 Аварийные режимы

🚑 Скорая

Мгновенный приоритет.
Зелёный за <5 секунд.
Автоматически по классу «emergency» от CV.

🚛 Застревание

inside > 0 дольше порога → EMERGENCY STOP.
Защита от drift счётчиков и реальных ЧП.

📷 Потеря камеры

Нет heartbeat >5с → алерт.
Обе камеры потеряны → fallback на фиксированный таймер (не слепой стоп).
