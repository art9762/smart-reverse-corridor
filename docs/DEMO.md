# Сценарий демо для жюри (5–7 минут)

1. **0:00–0:30. Контекст.** Двухполосная дорога, ремонт, реверсивные светофоры. Сегодня — таймер. Что не так — показываем.
2. **0:30–1:30. Baseline.** Запускаем симулятор в режиме фиксированного таймера 3/3 мин. Создаём асимметричный поток. Очередь растёт, throughput падает. На графике — красная зона.
3. **1:30–3:30. Adaptive.** Переключаемся на наш контроллер. Очередь рассасывается, throughput восстанавливается. Показываем дашборд: фазы, счётчики, инсайт-зона.
4. **3:30–4:30. Безопасность.** Запускаем сценарий «фура застряла» — система не переключает фазу, поднимает alert.
5. **4:30–5:30. Скорая.** Эмулируем спецтранспорт, нажимаем приоритет — мгновенное YELLOW+ALL_RED+GREEN. ETA на проезд.
6. **5:30–6:30. Потеря камеры.** Глушим одну камеру — fallback на безопасный таймер, alert оператору.
7. **6:30–7:00. Цифры.** Сравнение «до/после»: throughput +X%, задержка −Y%, аварийные смены фазы = 0 vs 2 в baseline.
